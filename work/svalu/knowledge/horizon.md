# Blue Horizon

Blue Horizon은 포트폴리오에 사용하는 가명이다. 컨택센터 운영 플랫폼 UI 리뉴얼 프로토타입이며, 회사명이나 실제 서비스 이름은 공개하지 않는다.

핵심은 관리자가 자리를 비워도 모바일로 운영 상황을 확인하는 것이다. PC는 여러 지표를 함께 비교하고, 모바일은 핵심 현황과 주의 항목부터 읽고 누르도록 배치한다. PC와 모바일을 별개 복사본으로 나누기보다 정보와 상태를 공유하고 폭에 맞게 구성한다. 그 이유에는 버전 변경, 수정과 검수 부담을 줄이려는 판단도 있다.

오래 보는 운영 화면에 맞춰 다크 모드의 배경·카드·글자 대비를 조정하고 경고의 강조를 구분한다. 글래스·플랫·네트워크 세 시안과 최종 프로토타입을 비교할 수 있다. 대시보드에서 상담원 현황과 AI 분석, 답변과 그래프로 이어진다.

희랑의 역할은 UI 설계와 퍼블리싱이며 실제 서비스 연결은 개발팀이 담당한다. 이 포트폴리오의 데이터와 AI 분석 화면은 체험용 예시다. 실제 운영 데이터나 서비스 성과로 설명하지 않는다.
