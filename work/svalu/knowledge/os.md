# OS UI

상담사는 고객과 대화하면서 이력을 찾고 메모를 남기며 여러 화면을 함께 사용한다. 희랑은 필요한 화면을 창으로 열어 함께 펼치는 구조를 디자인하고 퍼블리싱했다.

아이콘으로 창을 열고, 드래그로 위치를 옮기고, 최소화한 뒤 작업표시줄에서 복원한다. 앞의 작업을 남겨두고 다음 작업을 이어가기 위해 익숙한 OS 사용법을 업무 화면에 적용한다.

2023년에 희랑이 혼자 퍼블리싱해 인계한 창 구조가 기능이 더해진 2025년 제품에서도 유지됐다. 2025년 제품 전체를 혼자 개발했다는 의미는 아니다. 2026년에는 같은 창 구조를 관리자 도구로 확장했다.

포트폴리오에서는 로그인, 비밀번호 찾기의 모의 메일 반응, 대시보드와 전체 실적, 창 이동과 복원, 404 게임과 작업 복귀를 체험한다. 수치는 가상 데이터이며 실제 메일을 전송하지 않는다. 404는 실제 디자인을 살린 체험 화면이다.
