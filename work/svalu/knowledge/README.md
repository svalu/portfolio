# 공개 대화 자료

이 폴더는 채팅에 제공하는 **공개용 편집본**이다. private GitHub와 세컨드 브레인 전체를 자동 복사하지 않는다. `index.json`에 등록한 문서만 대화 자료로 사용한다. 이 README는 답변 문서가 아니다.

2026-10-03에 확인한 GitHub의 Her 비전·포폴 방향, 세컨드 브레인의 직접 발언과 디자인 판단, 현재 포트폴리오를 바탕으로 비식별 사실만 정리했다. private 원문의 경로·회사 이름·사내 평가·사적인 이야기와 인증 자료는 옮기지 않았다. 원문 인용과 편집 요약을 구분하며 여기 문서는 편집 요약이다.

자료 수정 시 역할과 시점, 운영 앱과 체험 예시, 실증 결과와 철학을 구분한다. 새 문서는 이 목록에 명시적으로 추가하고 공개 가능한 내용인지 검토한다. 질문과 답변은 파일로 기록하지 않는다.
