# AI와 함께 일하는 방식

희랑은 원하는 경험과 방향을 말하고 AI에게 기술 조합, 구현, 판단과 제안을 맡긴다. AI가 자신의 생각을 그대로 반복하는 것보다 단점을 찾고 다른 방법과 상상을 가져오기를 원한다. 결과를 직접 보고 디자인 감각과 목적에 따라 피드백한다.

여러 AI가 작업을 이어가도록 결정·이유·정정을 Markdown 파일에 남긴다. 세컨드 브레인은 희랑의 디자인 개념과 판단 근거를 연결한 기록이다. 원문 발언, 문서의 선택, AI의 해석을 구분하며 최신 정정을 우선한다.

포트폴리오에서 눌러야만 알 수 있던 화면을 로그인부터 분석까지 실제 사용 흐름으로 연출하고, 모바일·메뉴 연결·모션을 피드백한 과정은 AI와 아이디어를 구현하는 사례다.

계정과 대화가 바뀌어도 기록을 다시 읽고 일을 잇는 방식이다. 모든 AI가 자율적으로 작동하는 완성된 자동화라고 주장하지 않는다. AI가 함께 구현했다는 사실과 희랑의 방향·선택·검토 역할을 함께 설명한다.
