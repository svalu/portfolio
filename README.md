## 0. 한 줄

UX 엔지니어 희랑의 이직 포트폴리오. 한 페이지 스크롤. **"화려한 디자이너인 줄 알았는데 시스템을 만드는 사람이고, AI와 일하는 방식까지 설계했다"** 를 순서대로 보여준다.

## 1. 구조 — 차원을 지나가는 여정

- 모든 섹션은 **인트로와 같은 편집 체계**: 번호 · 큰 타이포 · 점 라인 · 색 띠 · 본문 · 실물 프레임. 색과 배경만 차원마다 바뀐다.
- 섹션들은 전부 `position:sticky` 로 같은 자리에 겹쳐 있고, 스크롤하면 **다음 차원이 3D 오브젝트 자리에서 원형으로 열리며** 이전 차원을 덮는다.
- 3D 오브젝트(빨간 유기체, Three.js)가 주인공. 차원마다 자리·크기를 바꿔 앉고, **색은 원이 열리기 전에 먼저 바뀐다** = "오브젠트가 색의 원천" 규칙. 인트로 3막의 번짐이 곧 차원 이동.

| 차원 | 내용 | 실물 | 상태 |
|---|---|---|---|
| 0 인트로 | 4막: 빨강 → 응축 → 등장(HEE/RANG·점·마크·직함·본문) → 번짐. 점 라인은 끝나면 색이 흐른다 | — | 완료 |
| 01 INTERFACE · **Blue Horizon** | 클라우드 컨택센터 운영 플랫폼 리뉴얼. **관리자가 폰에서도 본다**가 핵심 | 데스크톱 + 폰(390px 진짜 뷰포트) iframe | 완료 |
| 02 SYSTEM · **OS UI** | 상담 화면을 OS처럼, 2023 → 2026. 같은 관점을 3년 두 번 | 2023 상담사 화면(1440 렌더 축소) + 2026 관리자 OS | 완료 |
| 03 METHOD · Working with AI | AI 여럿과 석 달 이어서 일한 방법 (기억을 파일로, 실측이 구조를 바꿈) | 도식 예정 | 스텁 |
| 04 (예정) | svalu — 말투를 배우는 로컬 AI 아바타. 녹화 + "지금 깨어 있나" | 영상 | 미착수 |

## 1-B. 두 모드

- **데스크톱** `index.html` — 위의 차원 여정(sticky 스택, 원형 전환).
- **모바일** `m/index.html` — 폰(≤900px)으로 열면 자동 이동. sticky 대신 가벼운 세로 카드. 카드 = 차원, 같은 편집 체계·같은 오브젝트(우상단 작게, 카드마다 색이 먼저 바뀜). 카드 첫 문장이 훅. 실물은 **탭하면 새 탭에서 진짜가 열림**(Blue Horizon 은 반응형이라 폰에서 그대로, 데스크톱 전용 화면은 미니어처 + 안내). `?desktop=1` 이면 폰에서도 데스크톱 모드.

## 2. 파일 지도

```
index.html                 데스크톱 정본. 인트로 + 차원 전부 (CSS/JS 한 파일). 폰이면 m/ 로 보냄
m/index.html               모바일 모드. 히어로(빨강→응축→이름) + 카드 01~04 + 푸터
work/blue-horizon/         01 실물 (live.html 데스크톱·모바일 공용, ai-mode.html)
work/os-ui/2023/           02 실물 옛집 (jQuery, 창·작업표시줄)
work/os-ui/2026/           02 실물 새집 (React CDN, Win11식 데스크톱 셸)
assets/fonts/              Pretendard 가변 (로컬)
intro/                     인트로 단독 프로토타입 (index = 4막판, particles = 폐기안)
journey/                   폐기한 풍경(하야오 언덕)안. 참고용 보관
```

- 실물은 전부 **비식별 사본**. 원본 폴더는 공개 레포에 없다(.gitignore).
- 실물 iframe은 **현재 차원 ±0.9 안만 로드**하고 멀어지면 내린다(렌더 부하).

## 3. 디자인 규칙 (바꾸기 전에 읽을 것)

1. **흐름은 희랑의 영역.** 장을 추가·삭제·순서 변경하지 않는다. 하이라이트는 마지막 장(svalu) 하나.
2. 폰트 Pretendard. 큰 타이포 weight 200, 자간 -0.03em.
3. 이야기 있는 연출 우선. 상태 A→B 전환보다 **순서대로 등장**. 원 가장자리는 번지게(mask feather).
4. 모바일(≤900px)은 같은 체계를 세로로: 번호→타이포→소개→본문 2줄→실물 하나→띠. 01은 폰만, 02는 2026 미니어처만.
5. 회사 식별자 금지. 01은 **Blue Horizon** 가명만 쓴다.
