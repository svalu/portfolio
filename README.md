## 0. 한 줄

UX 엔지니어 희랑의 이직 포트폴리오. 한 페이지 스크롤. **"화려한 디자이너인 줄 알았는데 시스템을 만드는 사람이고, AI와 일하는 방식까지 설계했다"** 를 순서대로 보여준다.

## 1. 구조 — 차원을 지나가는 여정

- 모든 섹션은 **인트로와 같은 편집 체계**: 번호 · 큰 타이포 · 점 라인 · 색 띠 · 본문 · 실물 프레임. 색과 배경만 차원마다 바뀐다.
- 섹션들은 전부 `position:sticky` 로 같은 자리에 겹쳐 있고, 스크롤하면 **다음 차원이 3D 오브젝트 자리에서 원형으로 열리며** 이전 차원을 덮는다.
- 3D 오브젝트(빨간 유기체, Three.js)가 주인공. 차원마다 자리·크기를 바꿔 앉고, **색은 원이 열리기 전에 먼저 바뀐다** = "오브젠트가 색의 원천" 규칙. 인트로 3막의 번짐이 곧 차원 이동.

| 차원 | 내용 | 실물 | 상태 |
|---|---|---|---|

## 1-B. 한 파일, 두 폭 (2026-09-18 희랑 결정: PC/모바일 파일을 나누지 않는다)

- **파일은 `index.html` 하나. 마크업도 하나.** 희랑 원칙 — "버전 바뀌면 유지가 어렵고, 하나 고치면 둘을 봐야 하고, 검수가 암적으로 늘어난다."
- **≤900px(폰)** 은 CSS `@media (max-width:900px)` 한 겹 + JS `NARROW` 분기: sticky 스택·원 전환·스크롤 잠금·정착을 **끄고** 차원을 세로 카드로 흐르게 한다. 순서는 flex `order` 로만 바꾼다(번호→타이포→훅→소개→실물→본문→띠). 인트로는 3초(잠금 없음, 밀면 넘어감). 등장·색·iframe 로드는 IntersectionObserver.
- 오브젠트(폰): 인트로에서 오른쪽 가운데 크게 응축 → 첫 화면을 넘기며 우상단 작게, 차원마다 색을 먼저 입는다. 위치 식은 `frame()` 의 `if(NARROW)` 절(`data-mobj` 는 없앴다).
- 01(폰): 실물은 폰 하나. 탭(최종·시안 셋)이 그 폰의 iframe 을 갈아끼운다(9/18 희랑: "일관성 있게 처음 나오는 건 모바일로"). 시안 셋은 반응형이 아니지만 로그인 화면은 390 폭에 들어온다.
- `m/index.html` 은 **루트로 돌려보내는 리다이렉트만** 남았다(예전 링크 보호).

## 3. 디자인 규칙 (바꾸기 전에 읽을 것)

1. **흐름은 희랑의 영역.** 장을 추가·삭제·순서 변경하지 않는다. 하이라이트는 마지막 장(svalu) 하나.
2. 폰트 Pretendard. 큰 타이포 weight 200, 자간 -0.03em.
3. 이야기 있는 연출 우선. 상태 A→B 전환보다 **순서대로 등장**. 원 가장자리는 번지게(mask feather).
4. 모바일(≤900px)은 같은 마크업을 세로로(§1-B). 폰용 문장을 따로 쓰지 않는다 — 방향 표현("왼쪽", "오른쪽 폰")을 피하면 한 문장이 두 폭에 다 맞는다. 인트로 본문만 `.l2` 토막을 폰에서 접는다.
5. 회사 식별자 금지. 01은 **Blue Horizon** 가명만 쓴다.

### 5-B. counseling 2025 는 어떻게 만든 것인가

서버 JSP 50장을 정적 HTML 50장으로 되돌린 것. **화면을 다시 그리지 않았다** — JSTL 이 거의 없고 전부
Ajax 렌더라, `$.ajax` 를 가로채는 가짜 서버 한 장(`mock/mock-api.js`)만 새로 쓰면 제품의 원본 JS 가
그대로 표·차트·창을 그린다. 그래서 정렬·페이징·창 드래그·리사이즈가 실제로 동작한다.

- 원본에서 고친 곳: `js/dino.js` 이미지 경로, 안 쓰는 폰트 삭제. 그 외 마크업·JS 는 제품 소스 그대로.
- **아이콘 29개는 다시 그렸다**(2026-09-19 희랑 "아이콘 별로다, 일관성 있게"). 원본은 면·선이 섞여 있었다.
  한 규칙으로 통일: 24 그리드 · 선만 · 큰 것(시작메뉴 40px) 굵기 1.8 · 작은 것(20px) 2.2 · 둥근 끝 · 여백 3.
  파일명은 그대로라 CSS(`-webkit-mask-box-image`)·마크업은 손대지 않았다. 색은 CSS 가 입힌다(`--point_color_1`).
- `js/analytics/personal/performance.js` 는 막대차트 함수 4개가 주석 처리된 채 호출만 남아 있었다
  (서버에서도 ReferenceError). 그 주석 코드를 `mock-api.js` 의 RESTORED 절에 그대로 되살렸다.
- 폰트는 실제 쓰는 656자만 남겨 woff2 서브셋: 23.6MB → 231KB. 첫 로드 약 1.2MB.
- 메뉴 트리는 MongoDB 에서 오던 데이터라 소스에 없다. 아이콘 파일명 18개로 되짚었고 **그룹 배치는 추정**이다.
- 소켓·SSE 는 `mock/mock-socket.js` 가 껍데기로 막는다. mock-api 안에서 덮는 것만으로는 안 됐다 —
  vendor 의 sockjs 가 뒤에 로드되고, `global-connection.js` 는 DOM ready 전에 이미 connect() 를 부른다.
- `file://` 로 열면 창이 손톱만 하게 열린다(부모가 iframe 문서를 못 읽어 크기 측정이 막힘). 서버로 열 것.
